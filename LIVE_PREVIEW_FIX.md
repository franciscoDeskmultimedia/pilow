## 🔍 Why Live Preview Wasn't Working

### The Problem

Live Preview relies on **`useLivePreview` hook** from `@payloadcms/live-preview-react`. This hook:

1. **Subscribes to real-time updates** from Payload CMS API
2. **Needs the correct `serverURL`** to connect to your backend
3. **Fetches draft content** directly from Payload while you type

### What Was Happening

- On Vercel, `NEXT_PUBLIC_SERVER_URL` wasn't set
- The component fell back to `localhost:3000` (which doesn't exist on Vercel!)
- LivePreview couldn't connect to the API
- Result: You only saw changes after publishing (not real-time)

### The Solution

- Set `NEXT_PUBLIC_SERVER_URL=https://pilow.vercel.app` on Vercel
- Now `useLivePreview` can connect to your deployed API
- Real-time updates work as expected! ✨

## 📚 How It Works (Technical Details)

### Draft Mode Flow:

```
1. User clicks "Live Preview" in Payload Admin
   ↓
2. Payload generates a preview URL: `/api/draft?url=...&secret=...`
   ↓
3. Next.js draft route (`/api/draft/route.ts`) checks the secret
   ↓
4. If valid, enables Draft Mode and redirects to the page
   ↓
5. Page component checks `draftMode().isEnabled`
   ↓
6. Fetches DRAFT content from Payload (via `draft: true` query param)
   ↓
7. LiveContent component subscribes to updates via `useLivePreview`
   ↓
8. As you type, Payload API pushes updates to the preview 🎉
```

### Key Components:

- **`/api/draft/route.ts`**: Enables Next.js draft mode
- **`src/lib/payload.ts`**: Fetches draft or published content based on draft mode
- **`LiveContent.tsx`**: Renders blocks with real-time updates
- **`useLivePreview` hook**: Subscribes to Payload API for live updates
